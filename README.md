1. Pengertian Bootstrap Bootstrap adalah kerangka kerja (framework) CSS dan JavaScript open-source yang digunakan untuk membangun tampilan situs web yang responsif dan berorientasi mobile-first secara cepat dan terstruktur. 
2. Memasang Bootstrap Terdapat dua cara utama untuk mengimpor atau menggunakan Bootstrap pada proyek: 
•	Melalui CDN (Content Delivery Network): Menambahkan tautan <link> CSS dan <script> JavaScript dari server CDN langsung ke dalam file HTML.
•	Melalui Unduhan Lokal/Package Manager: Mengunduh file source Bootstrap secara manual atau melalui manajer paket seperti npm, lalu memanggil file lokal tersebut di dalam proyek.
3. Grid dan Breakpoint
•	Class Grid: Sistem tata letak fleksibel berbasis 12 kolom yang disediakan Bootstrap untuk mengatur posisi elemen pada halaman secara terstruktur. 
•	Breakpoint: Titik batas ukuran lebar layar (misalnya sm, md, lg, xl) yang digunakan oleh sistem grid untuk mengubah tata letak agar beradaptasi dengan ukuran layar perangkat pengguna. 
4. Class Bootstrap Lima contoh class Bootstrap beserta kegunaannya: 
•	container: Membungkus konten halaman dan memberikan batas (margin) agar terpusat secara otomatis.
•	row: Membuat baris horizontal baru yang berfungsi sebagai pembungkus komponen class kolom (grid).
•	col: Menentukan ukuran atau proporsi kolom di dalam sistem grid.
•	btn: Memberikan gaya (desain) dasar standar Bootstrap untuk elemen tombol.
•	shadow: Menambahkan efek bayangan (drop shadow) pada elemen untuk memberikan dimensi kedalaman.
5. menambahkan class img-fluid pada tag <img>. Class ini menerapkan properti max-width: 100%; dan height: auto; sehingga gambar mengecil secara proporsional sesuai penampungnya
